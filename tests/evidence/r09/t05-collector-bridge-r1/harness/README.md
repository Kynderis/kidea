# R09 collector integration

CREATE-only local proof for the least-read C++ collector bridge. The runner
freezes the exact release binary, Pilot observer, plan files, tool binaries and
Docker images; uses an internal network with no host ports; and retains every
raw result. It starts the actual backend collector behind private Caddy TLS,
feeds the actual observer, and verifies the fallback in Chromium.

The owned database fixture creates one pending workshop operation plus an
over-capacity invariant before the server starts. The real updater must detect
the invariant and leave the real outbox obligation pending. The proof verifies
per-signal UNKNOWN, private-token
denial, boot change, durable known-critical history, source loss and session
revocation. The dashboard probe is a declared Caddy fixture. This does not
prove an independent host, backup/restore, WQ, backend admission, Human on-call,
release acceptance, Apple Silicon or Windows.
